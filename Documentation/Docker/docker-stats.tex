\chapter{Docker Container \& Process Monitor}
\label{app:dockermonitor}

The \textbf{Docker Container \& Process Monitor} is a desktop application written in Rust and powered by \texttt{eframe}/\texttt{egui}. It provides real-time telemetry, interactive process trees, resource utilization leaderboards, historical performance graphing, and live container logging. This manual details application installation, interface navigation, and key feature workflows.

\section{Introduction \& System Requirements}

The application communicates directly with your local Docker Engine via standard UNIX socket or named pipes. It provides an intuitive, responsive user interface without requiring web browsers or external cloud dependencies.

\subsection{Key Features}
\begin{itemize}
    \item \textbf{Collapsible Sidebar Navigation:} Toggleable menu icon providing access to all application views.
    \item \textbf{Live Container Table:} Real-time updates for CPU usage, memory consumption, network I/O (RX/TX), process IDs, and exposed ports.
    \item \textbf{Process Tree Inspection:} Drill down into individual containers to view running OS processes and multi-threading stats.
    \item \textbf{Performance Leaderboard:} Aggregate system overview highlighting top CPU and Memory consuming containers along with total process/thread metrics.
    \item \textbf{Real-Time Telemetry Graphs:} Historical plotting for total CPU utilization, memory allocation, and network traffic.
    \item \textbf{Streaming Log Viewer:} Dedicated multi-window log streaming for inspectable container stdout/stderr output.
\end{itemize}

\subsection{System Prerequisites}
\begin{itemize}
    \item \textbf{Operating System:} Linux, macOS, or Windows 10/11.
    \item \textbf{Docker Engine:} Docker Daemon running locally (v20.10+ recommended).
    \item \textbf{User Permissions:} Sufficient user group privileges to query the Docker socket (\texttt{/var/run/docker.sock} on Linux/macOS).
\end{itemize}

\subsubsection{Interactions \& Actions}
\begin{itemize}
    \item \textbf{Expand Container ($>$ / v):} Click the arrow icon next to a container name to spawn a background query fetching live processes running inside that container.
    \item \textbf{Process Status Hover:} Hovering over process status codes (e.g., \texttt{Ss}, \texttt{R+}, \texttt{Z}) reveals detailed process state definitions (e.g., Interruptible Sleep, Session Leader).
    \item \textbf{Context Menu \& Double Click:} Right-clicking a container row opens a context menu. Double-clicking or selecting \textit{View Logs} opens a dedicated log streaming window.
\end{itemize}

\subsubsection{Summary Metrics}
\begin{itemize}

    \item \textbf{Leaderboards:} Ranked top 5 consumers for both CPU and Memory usage.

\section{Troubleshooting \& Error Handling}
\begin{itemize}
    \item \textbf{Docker Connection Errors:} If the app cannot communicate with Docker, an error panel appears on startup. Ensure Docker service is active (\texttt{systemctl status docker} or Docker Desktop).
    \item \textbf{Missing Processes:} Process details require elevated container permissions or appropriate Linux \texttt{ps} capabilities inside the container image.
\end{itemize}
